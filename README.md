# 弓箭之间 (AmongBows)

author `AerMini` on `2026/9/10`

> 这个玩法是做梦梦到的，后面完善了一下

---

## 一、游戏概述

| 项目 | 内容 |
|------|------|
| 游戏名称 | 弓箭之间 (AmongBows) |
| 建议人数 | 4~16 人 |
| 游戏时长 | 约 8~15 分钟 (取决于地图、玩家密度与玩家智力) |
| 核心类型 | 多人远程对战 + 队伍推理伪装 |
| 队伍数量 | 2~4 队 |
| 单局时间 | 默认30分钟 |

---

## 二、队伍分配

根据当前玩家总数，**穷举所有合理的分队方案**，若存在多种方案则**随机选取其中一种**。这样其他玩家在准备阶段无法提前得知本局会分为几个队伍

**规则：**
- 每个方案中，各队人数尽量均分
- 队伍颜色：`红`/`蓝`/`黄`/`绿` 四队，在选定的方案内随机分配

**方法：**

| 玩家数 | 分队方案 |
|--------|-------------------------------|
| 2(不建议) | `2队(1+1)` |
| 3(不建议) | `3队(1+1)` |
| 4 | `2队(2+2)` 或 `4队(1+1+1+1)` |
| 5 | `2队(2+3)` 或 `3队(1+2+2)` |
| 6 | `2队(3+3)` 或 `3队(2+2+2)` |
| 7 | `2队(3+4)` 或 `3队(2+2+3)` |
| 8 | `2队(4+4)` 或 `3队(2+3+3) 或 4队(2+2+2+2)` |
| 9 | `3队(3+3+3)` 或 `4队(2+2+2+3)` |
| 10 | `3队(3+3+4)` 或 `4队(2+2+3+3)` |
| 11 | `3队(3+4+4)` 或 `4队(2+3+3+3)` |
| 12 | `3队(4+4+4)` 或 `4队(3+3+3+3)` |
| 13 | `4队(3+3+3+4)` |
| 14 | `4队(3+3+4+4)` |
| 15 | `4队(3+4+4+4)` |
| 16 | `4队(4+4+4+4)` |

每位玩家在游戏开始时会知道自己的真实队伍，并默认穿戴随机队服。队服颜色不代表真实队伍

## 三、游戏流程

```
【阶段一：准备】 (约15秒)
  ├─ 玩家传送至出生点区域
  ├─ 玩家知晓自身真实队伍
  ├─ 玩家有15秒时间穿戴队服(超时自动穿戴本队队服)
  ├─ 游戏开始倒计时
  └─ 初始物品发放: 4套队服+初始物资

【阶段二：战斗】 
  ├─ 掉落物开始刷新 (首次30秒，之后每45秒一波)
  ├─ 随机事件按周期进行随机触发
  └─ 虚空生效

【阶段三：结算】
  ├─ 满足胜利条件 -> 停止倒计时
  ├─ 广播获胜队伍，展示排名与统计
  └─ 等待下一局或退出
```

## 四、胜利条件

满足以下**任意一条**，该队即获胜:

**条件A (人数压制)**
己方存活人数 ≥ 其他所有队伍存活人数之和 + 1，且**持续15秒内己方无人受伤**

> `受伤`定义 请见下方[定义](#十三定义)

**条件B (全员淘汰)**
除己方队伍外的所有人全部已死亡或已淘汰

> `死亡` `淘汰`定义 请见下方[定义](#十三定义)

## 五、基础规则

### 5.1 初始属性

| 属性(单位) | 数值 |
|------|------|
| 生命值(HP) | 10 HP |
| 最大生命值上限(HP) | 15 HP |
| 箭矢(支) | 5+[全局玩家数/2] |
| 个人技能点(点) | 3 |
| 队伍共享技能点(点) | 5 |
| 弓-冷却时间(秒) | 2 `每次射箭后` |

### 5.2 误伤

| 场景 | 攻击者HP变化 | 队友HP变化 |
|------|--------|-----------|
| 普通箭矢命中队友 | -5 HP | -3 HP |
| 一击必杀命中队友 | -5 HP | -5 HP |

> 注：一击必杀的`额外伤害`不对队友生效，只触发`基础伤害`(队友-5HP)

### 5.3 队服与伪装

- 每位玩家持有**全部4套队服** (红/蓝/黄/绿)
- 玩家可以**随时切换**队服 (切换有5秒冷却)
- 队服颜色!=真实队伍

### 5.4 下落与复活

- 玩家掉入虚空后，立即受到**5HP**伤害
- HP扣除后，若玩家仍处于存活状态，则进入10秒重回战场倒计时，期间玩家变成旁观者，无法参与游戏
- **10秒重回倒计时**
  - 倒计时期间玩家处于`relive`状态
- 10秒后自动在**最近的安全落脚点**重生
  - 重生后的玩家初始最多仅**6 HP**，并会扣除**亏欠的HP** (即处于死亡状态时未能成功扣除的多出的HP)
  - 获得 **1秒无敌时间**

> `安全落脚点`定义 请见下方[定义](#十三定义)

### 5.5 治疗

- 每人初始拥有 **2次** 治疗机会
- 可通过拾取掉落物(治疗药水等)**增加次数**
- 治疗无使用冷却
- 使用方式：左右任一键点击目标玩家 或 丢弃为自身治疗
- 为他人治疗:
  - 治疗者: 扣除 2HP
  - 被治疗者: 恢复 5HP
- 为自己治疗：
  - 自身恢复 3HP

### 5.6 猜测

打开猜测UI -> 选择目标玩家 -> 选择要猜测的队伍(**UI中不会显示自己所在的队伍**)：

- **猜测正确：**
  - 获得 1支箭
  - 目标玩家在计分板获得`bright`永久标记
  - 进入 5秒猜测冷却
- **猜测错误：**
  - 自身扣除 2HP
  - 猜测冷却增加 20秒 (会在累计冷却基础上叠加)

> `标记` 请见 [十五、标记](#十五标记)

## 六、技能

### 6.1 技能点规则

| 项目 | 值 |
|------|---|
| 个人技能点初始 | 3 点 |
| 个人技能点上限 | 10 点 |
| 击杀敌方玩家 | +2 点 |
| 拾取技能点包 | +1 点 |
| 队伍共享技能点初始 | 5 点 |
| 队伍技能点击杀获得 | +1 点 |
| 队伍技能点拾取获得 | +1 点 |

### 6.2 技能列表

| 技能名 | 消耗 | 效果 | 单技能冷却时间 |
|-------|------|------|--------------|
| **传送** | 个人2点 或 队伍2点 | 传送到箭矢的落地位置 | 15秒 |
| **一击必杀** | 个人3点 或 队伍3点 | 下次箭矢命中额外造成5HP瞬间伤害 | 0秒 |
| **复活** | 个人5点 或 队伍5点 | 复活一名已死亡的玩家 | 45秒 |

### 6.3 技能释放方式

- 所有技能通过**弓**释放
- 手持弓 左键打开UI选则使用的技能
- 瞄准方向射出技能箭
- 受2秒弓冷却限制
- 未命中时技能点**不退还**

## 九、随机事件
随机事件存在以下内容. 每90秒触发一次随机事件.

| 编号 | 名称 | 效果 |
|------|-----|------|
| 1 | 服装危机 | 随机1~3名玩家强制换上与其真实队伍不符的队服，并会广播玩家名字 |
| 2 | 生命涌动 | 所有存活玩家恢复3HP |
| 3 | 腐蚀之雨 | 所有存活玩家在30秒内每5秒受到1点伤害 |
| 4 | 充能 | 所有玩家个人技能CD刷新，个人技能点+1，各队伍技能点+2 |
| 5 | 真相时刻 | 所有穿戴错误队服的玩家名2秒后在计分板上变成粉色, 持续3秒. 整局游戏最多触发2次该事件 |
| 6 | 空投 | 随机位置降落道具箱，内含1~2个随机道具 |
| 7 | 体质增强 | 所有玩家获得速度II、跳跃II效果，持续30秒 |
| 8 | 弱箭 | 所有伤害减半(向下取整)，所有玩家获得3支临时箭矢. 该事件效果持续15秒 |

## 十一、地图生成配置

该部分请见 [十、配置](#十配置) 中的 `config.yml` 的 `map` 部分

**生成规则 (generate=true):**
- 柱子默认由红/蓝/黄/绿混凝土构成
- 随机生成不同高度的平台层，每层有若干落脚点(随机方块)
- 任意两平台之间的垂直高度差 <= `max_height_diff`, 确保所有玩家可通过跑酷到达
- 可随机在空中生成辅助跳跃方块
- 若 `generate=false`, 使用固定的内置预设地图

## 十三、定义
- `受伤` 被箭矢命中、被技能命中、队友误伤（双向伤害）、DoT持续伤害. **不包含**：坠落伤害、环境伤害、自伤
- `死亡` 玩家HP归0，但仍可被复活
- `淘汰` 玩家HP归0，且已被复活过. 已淘汰的玩家不可再被复活，也无法继续参与对局
- `复活` 处于死亡玩家的状态重生回到战场

## 十四、线索
线索存在以下内容.

| 编号 | 内容 | 答案 | 随机出现时的概率 |
|------|-----|------|----------------|
| 1 | 该玩家当前持有的某个道具与其数量 | 道具名 (道具数量) | 35% |
| 2 | 该玩家当前队服是否真实 | 是 or 否 | 30% |
| 3 | 周围10格内有多少名玩家穿着错误的队服 | 符合条件的玩家数量 | 15% |
| 4 | 周围10格内有多少不同于自己队伍的玩家 | 符合条件的玩家数量 | 5% |
| 5 | 该玩家的真实队伍 | 玩家队伍 | 1% |

## 十五、标记
标记存在以下内容.

| 文本 | 颜色 | 含义 | 触发时机 | 持续时间 | 可见范围 |
|------|-----|------|---------|---------|----------|
| `✈` | 紫色`&5` | 正在拉弓/选择技能 | 拉弓或打开技能选择UI | 直到该状态结束 | 所有人 |
| `✈` | 蓝色`&b` | 已发射箭/已释放技能 | 弓射出后 | 2s | 所有人 |
| `▼` | 粉色`&d` | 最近受到伤害 | 受击后 | 3s | 所有人 |
| `★` | 橙色`&6` | 已被其他玩家猜对真实队伍 | 有人猜测正确后 | 永久 | 所有人 |
